## Features
- Create a new list: each list has a unique URL. 
  - It can be shared to other people thanks to this URL

- see the list
  - anyone with access to the list can see it

- Modify the list
  - anyone with access to the list can modify it.
  - anyone who access to the list, is assigned with a random color, and every modifications made are highlighted with this color (inspiration: etherpad application)

- Add an item to the list
  - Each item has a name
  - Each item can have a description

- Edit an item of the list

- Remove an item from the list

- Delete the list
